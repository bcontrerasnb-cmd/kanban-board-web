# 📋 Interactive Kanban Board (Web UI)

Aplicación web interactiva para la gestión visual de tareas y flujo de trabajo mediante metodología Kanban.

## 🛠️ Tecnologías Utilizadas
* **Core:** JavaScript vanilla (ES6+)
* **Interfaz:** HTML5 Semántico, CSS3 Custom Properties
* **Persistencia Local:** LocalStorage API

## 🚀 Funcionalidades
- Creación, edición y eliminación dinámica de tarjetas de tareas.
- Transición entre estados (Pendiente, En Proceso, Completado).
- Persistencia de datos en el cliente para mantener el estado tras recargar.
- Diseño responsivo adaptado a escritorios y móviles.
